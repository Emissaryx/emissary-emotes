EMISSARY EMOTES
Version 1.0

A modern emote browser for Return of Reckoning.

Emissary Emotes provides a quick, organized way to browse and play available emotes without having to remember every command.

FEATURES

- 83 emotes organized alphabetically
- All, Favorites, Recent, Social, Poses, and Fun categories
- Four-column emote browser
- Previous/Next page navigation
- Simple hover tooltips showing the emote command
- Right-click an emote to add or remove it from Favorites
- Recent emotes list for quick access
- Black and gold Emissary-themed interface
- Movable main window
- Custom movable Emissary launcher icon
- Launcher position is saved

LAUNCHER ICON

Left-click:
Opens or closes the Emissary Emotes window.

Right-click:
Locks the launcher icon in place.

Right-click again:
Unlocks the launcher icon so it can be moved.

The chat window will confirm whether the icon has been locked or unlocked.

When unlocked, drag the icon to place it where you want it on your UI. Its position is saved.

USING EMOTES

Left-click an emote:
Plays the selected emote.

Right-click an emote:
Adds or removes that emote from Favorites.

Hover over an emote:
Displays the emote command.

CATEGORIES

All
Displays all available emotes in alphabetical order.

Favorites
Displays emotes you have marked as favorites.

Recent
Displays recently used emotes.

Social
Social and interaction-oriented emotes.

Poses
Pose and stance-oriented emotes.

Fun
Fun and expressive emotes.

INSTALLATION

1. Extract the EmissaryEmotes folder.
2. Place it in:

   Return of Reckoning/Interface/AddOns/

3. The final path should look like:

   Return of Reckoning/Interface/AddOns/EmissaryEmotes/

4. Start or reload Return of Reckoning.

If replacing an older development version, delete the old EmissaryEmotes folder before installing the new version.

CONTROLS

Launcher icon:
Left-click = Open/Close
Right-click = Lock/Unlock movement

Emote:
Left-click = Play
Right-click = Favorite/Unfavorite

Navigation:
Use the category tabs across the top and Previous/Next controls at the bottom.

SLASH COMMANDS

/ee
Opens or closes the Emissary Emotes window.

/ee icon
Shows or hides the launcher icon. The setting is saved between sessions, so players can use Emissary Emotes entirely through /ee if they prefer.

/emissaryemotes
Long-form alias for /ee.

RESIZING THE WINDOW

Drag the // grip in the bottom-right corner of the Emissary Emotes window to resize it.
The title bar still moves the window normally.

The addon remembers the exact width and height you leave it at. As the window changes
size, the emote grid automatically adjusts its columns, rows, and button widths.
