# Emissary Emotes

Source for the [Emissary Emotes addon](https://addons.returnofreckoning.com/addons/emissary-emotes) for Return of Reckoning.

The addon currently published on the repository is version 1.0.0. The source package is in `EmissaryEmotes/`.

## Contributing

Open an issue to discuss a change, then fork this repository and submit a GitHub pull request. Keep the addon package layout intact and include changes to the `.mod`, Lua, XML, and asset files as needed. Please describe how the change was checked in game.

## Publishing

The addon repository is linked to this public GitHub repository. Future releases can be published by pushing a version tag such as `v1.0.1`. The addon site reads the version from the tag and replaces the `.mod` placeholders while packaging. Releases still follow the addon's normal review or trusted-maintainer approval process.

The package README is in `EmissaryEmotes/README.txt`.
